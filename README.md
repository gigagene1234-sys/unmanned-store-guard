# StoreGuard Hub v0.2.1 Safe

DMSS와 안시포스 식음 ASP를 그대로 사용하면서 필요한 이벤트/거래 정보만 **사용자 동의 기반**으로 로컬 수집하는 Android 관리 허브입니다.

## 이번 버전에서 바뀐 핵심

v0.1의 안시포스 수집에 사용했던 **Android AccessibilityService를 완전히 제거**했습니다.

대신 Android 공식 MediaProjection 화면 공유 흐름을 사용합니다.

1. 사용자가 StoreGuard에서 **POS 수집 시작**을 누름
2. Android가 자체 화면 공유 승인창을 표시
3. 사용자가 승인한 세션에서만 StoreGuard가 화면 프레임을 읽음
4. 기기 내부 ML Kit 한국어 OCR로 거래 행을 추출
5. 원본 화면/스크린샷/원문 OCR은 저장하지 않음
6. 거래 형식에 맞는 최소 데이터만 Room DB에 저장
7. 15분 후 자동 종료, 또는 지속 알림의 **중지** 버튼으로 즉시 종료

Android 14+가 요구하는 mediaProjection foreground service 유형과 권한을 사용합니다.

## 자동화 수준

### 자동
- DMSS 알림 발생 시 이벤트 시각/제목/내용 로컬 저장
- POS 수집 세션 중 1.5초 간격으로 화면 OCR
- 안시포스 거래 후보 자동 파싱
- 초 단위 승인시각, 결제수단, 정상/취소 상태, 금액 저장
- 중복 거래 제거
- CCTV/POS 시간 오프셋 진단
- 15분 후 POS 캡처 자동 종료

### 사용자 승인 필요
- 최초 DMSS 알림 접근
- POS 수집 세션 시작 시 Android 화면 공유 승인

이 승인 절차를 우회하거나 자동으로 눌러주는 코드는 포함하지 않습니다.

## 저장하지 않는 정보

- DMSS/안시포스 비밀번호
- 화면 캡처 이미지
- 전체 OCR 원문
- 카드번호/개인 계정정보
- 얼굴 신원정보

## 이상징후 설계 원칙

향후 방문자 추적/이상징후 모듈은 다음을 지킵니다.

- 얼굴 신원 식별이 아닌 **일회성 익명 방문 ID**
- 결제 여부와 행동 분석을 별도 처리
- 결제했다고 자동 정상 판정하지 않음
- 이상행동을 자동으로 절도라고 확정하지 않음
- `정상 후보 / 검토 필요 / 연결 불확실`처럼 사람이 검토할 대상을 줄이는 용도로만 사용

## 첫 실기기 테스트

1. APK 설치
2. StoreGuard 실행
3. DMSS 이벤트 자동수집을 쓰려면 **DMSS 알림 접근** 허용
4. **POS 수집 시작** 누르기
5. Android 화면 공유 승인
6. 자동으로 열린 안시포스에서 매출내역 화면 보기
7. StoreGuard로 돌아와 최근 POS 거래에 실제 거래가 수집됐는지 확인
8. DMSS 알림 1건을 발생시켜 최근 DMSS 이벤트에도 들어오는지 확인

안시포스 OCR은 실제 화면의 글자 배치에 따라 추가 보정이 필요할 수 있습니다. 그래서 v0.2의 첫 성공 기준은 **실제 거래 1건 이상 자동 추출**입니다.
